• Hybrid retrieval: run keyword (BM25) and dense search in parallel and fuse the lists. Reciprocal rank fusion (RRF) is simple and robust: score(d) = Σlists 1/(k + rank(d)), with k ≈ 60. It needs no score normalisation because it uses ranks only.
  • Reranking: a cross-encoder reads query and passage together and outputs a relevance score. Much more accurate than comparing separate embeddings, but too slow to run on the whole corpus, so it re-scores the top 50–200 candidates. LLMs can also rerank (listwise), at higher cost.
  • Metadata filtering: restrict results by fields like tenant, department, document type, language, date or permissions. Pre-filtering applies the filter during search; post-filtering after, which can leave too few results when the filter is selective. Permission filters must never be post-hoc "best effort" (10.6).
  • Context assembly: deduplicate overlapping chunks, merge adjacent chunks from the same document, order by relevance (or by document position for readability), label each with a citation ID, and fit the token budget (7.3).

# pip install bm25s sentence-transformers faiss-cpu ollama
import bm25s, faiss, numpy as np, ollama
from sentence_transformers import SentenceTransformer, CrossEncoder
docs = ["To reset your password, open Settings > Security and choose Reset.",
        "Error E-4012 means the payment processor rejected the card.",
        "Invoices are emailed on the 1st of each month and can be downloaded in Billing.",
        "If you cannot sign in, check that your 2FA device clock is correct.",
        "Refunds are available within 14 days of purchase for annual plans."]
bm = bm25s.BM25(); bm.index(bm25s.tokenize(docs))
emb = SentenceTransformer("BAAI/bge-small-en-v1.5")
V = emb.encode(docs, normalize_embeddings=True); index = faiss.IndexFlatIP(V.shape[1]); index.add(V)
rerank = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")

def retrieve(q, k=4):
    kw, _ = bm.retrieve(bm25s.tokenize(q), k=k)                     # doc indices
    _, dn = index.search(emb.encode([q], normalize_embeddings=True), k)
    rrf = {}
    for ranking in (kw[0], dn[0]):
        for r, d in enumerate(ranking): rrf[int(d)] = rrf.get(int(d), 0) + 1 / (60 + r + 1)
    cands = sorted(rrf, key=rrf.get, reverse=True)
    scores = rerank.predict([(q, docs[d]) for d in cands])
    return [cands[i] for i in np.argsort(-scores)][:3]

q = "I can't log in"
ctx = "\n".join(f"[{d}] {docs[d]}" for d in retrieve(q))
prompt = f"Answer using only the sources. Cite like [n]. If not answerable, say so.\n{ctx}\nQuestion: {q}"
print(ollama.chat(model="qwen2.5:1.5b", messages=[{"role": "user", "content": prompt}]).message.content)
