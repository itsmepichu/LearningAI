Preference data: for one prompt, two or more responses and a judgement of which is better (from humans or a model).
Reward model: a model trained on preference data to output a scalar score for (prompt, response).
RLHF (reinforcement learning from human feedback): generate responses, score them with the reward model, update the policy (the LLM) with an RL algorithm such as PPO to increase reward, with a KL penalty to the original model so it does not drift into exploiting the reward model.
DPO (direct preference optimisation, 2023): skip the reward model and RL loop; a closed-form loss directly increases the probability of the preferred response relative to the rejected one, relative to a frozen reference model. Simpler and more stable; widely used for open models.
RL with verifiable rewards (RLVR): when correctness can be checked automatically (unit tests, maths answers, format rules), use that as the reward. Algorithms like GRPO sample several answers per prompt and reinforce the better-than-average ones. This is how "reasoning" models learn long chains of thought.

Prompt: "Customer asks for a refund outside the 14-day window." Chosen: polite explanation of the policy plus the escalation option. Rejected: "Sure, refund processed!" (violates policy).
