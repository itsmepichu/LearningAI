The best way to make the previous sections concrete is to run the whole loop at toy scale: tokenise text, build a model, compute cross-entropy on next-token prediction, follow gradients, watch loss fall, and sample. Below, a character-level bigram model (it predicts the next character from the current one) is trained with real gradient descent in your browser. It has one weight matrix of vocabulary × vocabulary logits. It is the smallest possible neural language model, and every concept (tokens, logits, softmax, cross-entropy, gradient, learning rate, sampling, temperature) is present.

Laptop lab: train a tiny GPT with nanoGPT Laptop · CPU · a few minutes

nanoGPT is a small, readable GPT training codebase. Its README gives a CPU recipe for a character-level Shakespeare model:

git clone https://github.com/karpathy/nanoGPT && cd nanoGPT
pip install torch numpy transformers datasets tiktoken tqdm
python data/shakespeare_char/prepare.py
python train.py config/train_shakespeare_char.py --device=cpu --compile=False \
  --eval_iters=20 --log_interval=1 --block_size=64 --batch_size=12 \
  --n_layer=4 --n_head=4 --n_embd=128 --max_iters=2000 --lr_decay_iters=2000 --dropout=0.0
python sample.py --out_dir=out-shakespeare-char --device=cpu

The README reports this takes about 3 minutes and reaches a validation loss of about 1.88: recognisably Shakespeare-like but garbled. Then read model.py (about 300 lines): you will find every component of 5.2–5.3. Experiments: change n_layer, block_size and learning rate and record the effect on loss. Karpathy's newer nanochat covers a full pretrain → SFT → RL → chat pipeline, but a meaningful run needs a node of several GPUs at once, which one Colab GPU cannot provide. Read its code and its report instead; the guide below runs the single-GPU version of the idea Needs external compute.

Toolbox for training

Transformers
models · tokenisers · Trainer

Load almost any open model, apply chat templates, and run training with Trainer. CPU works for small models.

Datasets
data loading · streaming

Load, stream, map and filter large datasets with memory-mapping; versioned via the Hub.

TRL
SFT · DPO · GRPO · reward models

Post-training library. SFTTrainer, DPOTrainer, GRPOTrainer. Try SFT on a 135M model on CPU; preference/RL runs need GPUs. The 13.3 Colab guide fine-tunes a 1.7B model on one free GPU.

datatrove
corpus processing at scale

Filtering, deduplication (MinHash) and extraction pipelines used to build large web datasets. Runs locally on samples.

DeepSpeed · FSDP
distributed training

ZeRO sharding, offload and pipeline parallelism. Learn the configs locally; real runs need several GPUs at once, more than one Colab GPU, so read them rather than run them. GPU

torchtitan · Megatron-LM
large-scale pretraining

Reference implementations of 3D/4D parallel pretraining. Read for architecture; they run only on clusters, not on one Colab GPU. GPU
