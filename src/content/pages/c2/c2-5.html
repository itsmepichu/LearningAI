Python is the working language of AI because its libraries wrap fast C, C++ and CUDA code. The core habit is vectorisation: express computation as whole-array operations instead of Python loops. A NumPy dot product over a million numbers runs in about a millisecond; a Python loop takes hundreds of times longer.

  • NumPy: n-dimensional arrays (ndarray), broadcasting (combining arrays of different shapes by stretching size-1 axes), linear algebra, random numbers.
  • pandas: tables (DataFrame) with named columns for loading, cleaning, joining and grouping data. Use it for evaluation results and datasets.
  • Matplotlib / seaborn / Plotly: charts. Always plot loss curves, metric distributions and error breakdowns; numbers alone hide problems.
  • Jupyter notebooks: interactive cells for exploration. Move code into modules once it stabilises, because notebooks hide execution order.

Reproducibility means another person (or you next month) gets the same result from the same inputs. In AI that requires pinning more than code: random seeds, library versions, data snapshots, model versions, prompt versions and hardware notes. GPU kernels are not always bit-for-bit deterministic, so record tolerance as well.

import numpy as np, pandas as pd, time, json, hashlib
rng = np.random.default_rng(seed=42)                 # explicit, seeded generator
x = rng.standard_normal(1_000_000)
t = time.perf_counter(); s = sum(v*v for v in x); loop = time.perf_counter() - t
t = time.perf_counter(); s2 = x @ x;              vec  = time.perf_counter() - t
print(f"loop {loop:.3f}s  vectorised {vec:.5f}s  speedup {loop/vec:.0f}x")
