Toolbox for chapters 2–4

NumPy
arrays · linear algebra

Foundation array library. Use it to build intuition by implementing similarity, softmax and gradient descent by hand.

pandas
tables · data cleaning

Load CSV/Parquet, clean, group and join. You will use it for every evaluation results table.

Matplotlib
plots

Loss curves, histograms, ROC curves. Plot before you trust a number.

JupyterLab
notebooks

Interactive exploration. Run jupyter lab in your environment.

scikit-learn
classical ML · CPU

Regression, trees, ensembles, clustering, metrics, splits and pipelines. Every exercise in chapter 3 runs on it.

PyTorch
deep learning · CPU or GPU

Tensors, autograd, training loops. The CPU build is enough for chapter 4 and tiny transformers.
