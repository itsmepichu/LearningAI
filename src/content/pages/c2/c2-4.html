Entropy H(p) = −Σ p(x) log p(x): the average "surprise" of outcomes drawn from p. A fair coin has 1 bit; a coin that always lands heads has 0.
Cross-entropy H(p, q) = −Σ p(x) log q(x): the average surprise when outcomes come from the true distribution p but you predicted q. It is the loss used to train language models: p puts all mass on the real next token, so the loss is simply −log q(real token).
KL divergence KL(p‖q) = H(p,q) − H(p): the extra surprise caused by using q instead of p. Always ≥ 0; zero only when q = p. Used in RLHF and DPO to keep a tuned model close to its original (6.5), and in distillation.
Perplexity = ecross-entropy (natural log): roughly "how many tokens the model is choosing between". Lower is better.
Example: reading a training log

A training log shows loss 2.30 at step 0 for a 10-class classifier. ln(10) = 2.30, which is exactly the loss of a uniform guess, so the model starts knowing nothing, as expected. For an LLM with a 50,000-token vocabulary, the initial loss should be near ln(50,000) ≈ 10.8. A first-step loss far from that suggests a bug in initialisation or labels.

In practice · HarborHarbor's reranker training log starts at loss ≈ ln(2) = 0.69 for a binary relevant/irrelevant head, exactly the uniform-guess value. A start far from that number signals a label or setup bug.
Failure to avoidEquating lower token loss with task success: a model can improve perplexity and still fail critical extraction or permission cases.
