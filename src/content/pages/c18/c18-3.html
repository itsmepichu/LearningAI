A gate is an automated check that blocks promotion when a threshold is not met. Gates make the acceptance criteria of 8.1 and the release criteria of 13.7 enforceable for every change.

Laptop lab: a quality gate in CI Laptop · CPU (runner) · or GitHub Actions
# .github/workflows/eval.yml (sketch) — runs promptfoo against a model endpoint on every PR touching prompts/
on: {pull_request: {paths: ["prompts/**", "promptfooconfig.yaml"]}}
jobs:
  eval:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npx promptfoo@latest eval -c promptfooconfig.yaml -o results.json
        env: {OPENAI_API_KEY: "${{ secrets.EVAL_API_KEY }}"}     # or point providers at a hosted test endpoint
      - run: python scripts/gate.py results.json --min-pass-rate 0.95 --critical-tag critical

gate.py is 20 lines: load results, compute pass rate overall and on cases tagged critical, exit non-zero if below thresholds. Locally you can run the same command against Ollama before pushing.
