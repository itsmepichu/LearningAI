Write a capacity and reliability plan

  1. Write explicit assumptions: DAU, requests per user, peak factor, token lengths, task duration.
  2. Compute peak RPS, average in-flight work, token demand and model/tool fan-out.
  3. Assign availability, latency, quality and cost SLOs per workload; define the degradation ladder.
  4. Load-test a mocked model gateway with an open-loop arrival rate, realistic lengths, tenant skew and one dependency failure.
