These workloads have different resource profiles, latency needs and failure modes. Running them on shared capacity lets one starve the others (a backfill saturating embedding GPUs that also serve query embeddings; long agent runs holding all model slots during peak chat).

Example

Monday 09:00: a large tenant triggers re-ingestion of 2M documents, and 40,000 employees open the assistant. Because query embeddings and ingestion embeddings run on separate pools, search latency stays at 40 ms while the backfill queue simply takes longer, within its freshness budget.
