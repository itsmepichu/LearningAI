Intuition

The same transformer block can be wired three ways, and the wiring decides what the model is good at. A reader that sees the whole page at once is best at understanding it. A writer that can only see what it has written so far is built for producing text. A translator first reads a whole sentence with one part of itself and then writes with another, looking back at what it read.

The only difference between these three is who may look at whom: the attention mask.

Example: picking architectures in one RAG system

A bi-encoder (encoder-only) embeds documents and queries for fast vector search; a cross-encoder reranker (encoder-only, reading query and passage together) re-scores the top 50; a decoder-only LLM writes the answer. Three transformers, three architectures, each matched to its job.

The numbers

Who can see whom. Count the allowed pairs with 4 output tokens and 5 input tokens:

  • Encoder-only, with 4 tokens: every token sees all 4, so 4 × 4 = 16 pairs.
  • Decoder-only, with 4 tokens: the first sees 1, the second 2, the third 3, the fourth 4, so 1 + 2 + 3 + 4 = 10 pairs.
  • Cross-attention: each of the 4 output tokens sees all 5 input tokens, so 4 × 5 = 20 pairs.

How much each text teaches. A decoder-only model gets a lesson at every position: a 1,000-token text gives 1,000 "what comes next?" questions. BERT hides about 15% of the tokens and learns only from those, so the same text gives about 150 questions.

Why the decoder can reuse work. In a decoder-only model, an earlier token never sees later tokens, so its keys and values do not change when a new token is added. They can be saved and reused (the KV cache). In an encoder, adding a token changes what every earlier token sees, so everything would have to be computed again.
