Query (Q), Key (K), Value (V): three vectors computed from each token's representation by learned matrices WQ, WK, WV. Intuition: the query says "what I am looking for", the key says "what I contain", the value is "what I will pass on".
Attention: Attention(Q,K,V) = softmax(QKᵀ / √d) · V. Each token's output is a weighted average of all values, weighted by how well its query matches each key. Dividing by √d (d = key dimension) keeps scores in a range where softmax does not saturate.
Self-attention: Q, K and V all come from the same sequence. Cross-attention: Q comes from one sequence (the decoder) and K, V from another (the encoder's output), as in translation.
Multi-head attention: run several attentions in parallel with different learned projections (e.g. 32 heads of dimension 128), then concatenate. Different heads learn different relations (syntax, coreference, position).
Causal mask: in a generator, token i may only attend to tokens ≤ i. Scores for future positions are set to −∞ before softmax, so their weight is exactly 0.
Example: what attention resolves

In "The server that crashed restarted", the verb "restarted" needs its subject. A trained head may put high weight from "restarted" onto "server", skipping "crashed". The output vector for "restarted" then contains information about the server, which later layers use to predict the next token (e.g. "at", "after").
