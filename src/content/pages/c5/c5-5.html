Logits: raw, unbounded scores the LM head outputs, one per vocabulary token. Higher = more likely.
Softmax: pi = ezi / Σj ezj. Converts logits to probabilities that are positive and sum to 1. Adding a constant to all logits changes nothing; only differences matter.
Autoregressive: each output token becomes part of the input for the next step. Generation is inherently sequential: token 50 cannot be computed before token 49.

Two phases matter for performance. Prefill processes the whole prompt in one parallel pass (fast per token). Decode then produces one token per forward pass (slow per token). To avoid recomputing keys and values for earlier tokens at each step, engines store them in the KV cache (14.1).

Example: softmax by hand

Logits for three tokens: [2.0, 1.0, 0.1]. e2 = 7.39, e1 = 2.72, e0.1 = 1.11, total 11.22. Probabilities: 0.66, 0.24, 0.10. If the true next token is the second one, its cross-entropy loss is −ln(0.24) = 1.42.

Laptop lab: look at real logits Laptop · CPU
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
name = "HuggingFaceTB/SmolLM2-135M"                      # 135M params, ~270 MB, fast on CPU
tok = AutoTokenizer.from_pretrained(name); model = AutoModelForCausalLM.from_pretrained(name)
ids = tok("The capital of France is", return_tensors="pt").input_ids
with torch.no_grad(): logits = model(ids).logits[0, -1]     # scores for the next token
probs = torch.softmax(logits, -1); top = torch.topk(probs, 8)
for p, i in zip(top.values, top.indices): print(f"{p:.3f}  {tok.decode(i)!r}")
out = model.generate(ids, max_new_tokens=12, do_sample=False)  # greedy autoregressive loop
print(tok.decode(out[0]))
