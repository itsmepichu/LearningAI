Intuition

Attention on its own has no sense of order: "dog bites man" and "man bites dog" contain the same tokens, and attention would treat them the same. So each token is also given its position, in a way that lets the model tell how far apart two tokens are.

A transformer is then a tall stack of identical blocks. Think of a shared notebook, one page per token, passed up through the stack: each block reads the page, writes a short note, and adds it to what is already there instead of rewriting the page. Normalising before each block keeps the handwriting a readable size, so a hundred blocks can be stacked without the numbers exploding or fading away.

Mechanism

Attention by itself treats its input as a set: shuffling tokens shuffles outputs identically. Word order must be injected as positional information.

  • Absolute positional embeddings (original transformer, BERT, GPT-2): add a learned or sinusoidal vector for position 1, 2, 3… to each token embedding.
  • RoPE (rotary position embedding), used by most current LLMs: rotate each query and key vector by an angle proportional to its position. The dot product between a query at position m and a key at position n then depends on m − n, i.e. relative distance. RoPE scaling methods are part of how context windows are extended after training.
  • ALiBi and similar methods add a distance-based penalty directly to attention scores.

A transformer block (layer) has two sub-layers, each wrapped in a residual connection (output = input + sublayer(input)) and normalisation. Residuals give gradients a direct path through all layers, which is what lets models stack 30–100+ blocks. Modern LLMs use pre-norm: normalise before each sub-layer (RMSNorm is common).

The feed-forward network (FFN / MLP) is applied to each position independently: expand the vector (often ~3.5–4× wider), apply a non-linearity (commonly SwiGLU), project back. About two-thirds of a dense model's parameters sit in FFNs, and they are thought to store much of the model's factual associations.

Example: counting an 8B model's parameters

Llama-3-8B-style shape: d = 4096, 32 layers, FFN width 14,336, vocabulary 128,256, grouped-query attention with 8 KV heads (each key and value head is shared by 4 query heads). Per layer: attention ≈ 4096×4096 (Q) + 2×4096×1024 (K,V) + 4096×4096 (O) ≈ 42M; FFN (SwiGLU has 3 matrices) ≈ 3×4096×14,336 ≈ 176M. 32 layers × 218M ≈ 7.0B, plus input and output embeddings 2×128,256×4096 ≈ 1.05B → ≈ 8.0B.

The math

RoPE. Split a query or key vector into pairs of dimensions. For the pair i of a token at position m, rotate by the angle m\theta_i, with frequencies falling geometrically across the pairs:

R_{m}^{(i)} = \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix}, \qquad \theta_i = 10000^{-2i/d}

Rotations compose by adding angles, and the transpose of a rotation is the rotation the other way, so the score between a query at m and a key at n depends only on the distance:

(R_m q)^\top (R_n k) = q^\top R_m^\top R_n\, k = q^\top R_{n-m}\, k

RMSNorm and the pre-norm block. With a learned gain g and a small \varepsilon:

\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\tfrac{1}{d}\sum_{j=1}^{d} x_j^2 + \varepsilon}} \odot g
h = x + \operatorname{Attn}(\operatorname{RMSNorm}(x)), \qquad y = h + \operatorname{FFN}(\operatorname{RMSNorm}(h))

Because each sub-layer is added, the gradient of the output with respect to the input is the identity plus the sub-layer's own gradient, \partial y / \partial x = I + \partial F/\partial x, so a path straight through all the layers always exists.

SwiGLU FFN. With \operatorname{Swish}(z) = z\,\sigma(z) and three matrices:

\operatorname{FFN}(x) = \big(\operatorname{Swish}(xW_1) \odot xW_3\big)\,W_2, \qquad W_1, W_3 \in \mathbb{R}^{d \times f},\ W_2 \in \mathbb{R}^{f \times d}

That is 3df parameters per layer: 3 \times 4096 \times 14336 \approx 176\text{M} for the 8B shape in the example above.
