Official documentation links were checked on 4 November 2026. Before using any tool, check its current installation steps, licence, supported versions and hardware requirements. Open-source code does not make every hosted service built on it free. "Laptop" means you can learn the tool on a CPU-only laptop at small scale; it does not mean production capacity.
