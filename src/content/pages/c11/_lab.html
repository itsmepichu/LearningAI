Build a recoverable tool workflow

  1. Implement search → draft → validate → approve → create as explicit states; mock the model at first.
  2. Persist state in SQLite (or a LangGraph SQLite checkpointer) and kill the process after each state.
  3. Inject a timeout after a successful create and retry with the same idempotency key.
  4. Add an agent-chosen search step bounded by a tool allowlist, deadline, step limit and spend limit.
