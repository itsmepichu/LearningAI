Chapter 8 lab · keep as evidence

Create a layered evaluation harness

  1. Version a dataset of 60 cases with input, user scope, evidence version, expected behaviour and severity.
  2. Add deterministic checks first, then a human rubric, then an optional model judge calibrated on 30 human-graded cases.
  3. Run nondeterministic cases five times and report failure rates by language and task type.
  4. Compare two prompt versions with a paired test and report the confidence interval.
