Intuition

There are three kinds of marker. A machine that checks the format and the numbers is instant, free and never tired, but it cannot judge whether an answer is helpful. A human expert can judge anything, but is slow and expensive, and two experts sometimes disagree. A model acting as judge sits in between: fast and cheap, but with blind spots you have to find first.

Use the machine for everything it can check, the model judge for volume, and the humans to keep the judge honest.

Mechanism

  • Deterministic checks (code): exact match, JSON validity, schema conformance, regex, "contains required citation", numeric tolerance, unit tests for generated code, SQL execution results, banned phrases. Cheap, fast, reproducible. Use them wherever possible.
  • Human evaluation: experts grade outputs against a rubric. The gold standard for nuanced quality (tone, helpfulness, correctness in specialist domains), but slow, expensive and itself variable. Use for calibration and for high-stakes decisions.
  • Model-based judges (LLM-as-judge): a model grades outputs using a rubric, either pointwise ("score 1–5 for groundedness") or pairwise ("which answer is better?"). Scales cheaply, but has biases (8.3) and must be validated against humans before you trust it.
Example: a judge rubric for groundedness
You are grading whether an ANSWER is supported by the SOURCES.
For each factual claim in the ANSWER, decide: SUPPORTED (stated or directly implied by a source),
NOT_SUPPORTED (absent from sources), or CONTRADICTED.
Return JSON: {"claims":[{"text":..., "verdict":..., "source_id":...}], "grounded": true|false}
"grounded" is true only if every claim is SUPPORTED. Ignore style. Do not use outside knowledge.

Claim-level verdicts make the judge's reasoning inspectable and give a finer score (fraction supported) than a single 1–5 rating.

The numbers

What each marker costs for 300 cases (illustrative):

MarkerCostTime
Code checksalmost nothingseconds
Model judge: 300 × 2,000 tokens600,000 tokens, a few dollarsminutes
Human experts at 2 minutes a case300 × 2 = 600 minutes, 10 hours of expert timedays

That is why code checks go first: every case they settle is one the judge and the humans do not need to see.

Code

The program runs six candidate answers through code checks: valid JSON, a known source, a length limit, banned phrases, and every number appearing in the source. Add an answer of your own to ANSWERS and run it again.
