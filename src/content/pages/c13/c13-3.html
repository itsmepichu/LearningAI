Full fine-tuning: update all weights. Maximum flexibility; needs ~16 bytes/parameter of training memory (6.6) and produces a full model copy per variant.
PEFT (parameter-efficient fine-tuning): freeze the base model and train a small number of new parameters.
LoRA (low-rank adaptation): for a frozen weight matrix W (d_out × d_in), learn two small matrices B (d_out × r) and A (r × d_in) with rank r ≪ d (e.g. 8–64). The layer computes W·x + (α/r)·B·A·x. Trainable parameters per matrix: r·(d_in + d_out). After training, B·A can be merged into W (no inference overhead) or kept as a swappable adapter.
QLoRA: store the frozen base model in 4-bit (NF4) to cut memory, train LoRA adapters in higher precision on top. Makes fine-tuning large models possible on a single GPU, at some speed cost.
Laptop lab: LoRA SFT on a 135M model Laptop · CPU · ~5–15 min
# pip install trl peft datasets transformers
from datasets import Dataset
from peft import LoraConfig
from trl import SFTConfig, SFTTrainer
rows = [("Invoice #4471 from Acme GmbH, total EUR 1,240.50", '{"vendor":"Acme GmbH","total":1240.50,"currency":"EUR"}'),
        ("Bill 88-12, Northwind Ltd, amount due GBP 99.00",   '{"vendor":"Northwind Ltd","total":99.00,"currency":"GBP"}')] * 60
data = Dataset.from_list([{"prompt": [{"role": "user", "content": f"Extract JSON: {x}"}],
                           "completion": [{"role": "assistant", "content": y}]} for x, y in rows])
trainer = SFTTrainer(
    model="HuggingFaceTB/SmolLM2-135M-Instruct", train_dataset=data,
    args=SFTConfig(output_dir="lora-out", num_train_epochs=2, per_device_train_batch_size=8,
                   learning_rate=2e-4, logging_steps=5, use_cpu=True, report_to="none"),
    peft_config=LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj", "v_proj"], task_type="CAUSAL_LM"))
trainer.train(); trainer.save_model("lora-out")      # saves only the adapter (a few MB)

The prompt/completion format makes TRL compute loss only on the completion (6.4). The toy data is tiny and repetitive, so the point is the mechanics: watch loss fall, then test on new invoice formats to see overfitting. For a real 1–8B model use a GPU notebook (Colab, Kaggle) with QLoRA via Unsloth or plain TRL + bitsandbytes Needs external compute.
