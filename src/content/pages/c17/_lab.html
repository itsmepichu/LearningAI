Instrument and investigate a controlled failure

  1. Create a root trace with retrieval, rerank, model, tool, queue and validation spans; propagate context across an async boundary.
  2. Record versions, durations, token counts and tenant-safe IDs; redact payloads before export.
  3. Inject a slow retriever and a duplicated tool retry; build a dashboard that shows both causes.
  4. Write an alert with a runbook, then turn the failure into an evaluation case.
