• Token accounting: record input, cached input, output and reasoning tokens per call (from the provider response, not estimates), with model and price version.
  • Cost attribution: tag every call with tenant, user (or hashed ID), feature, environment and prompt version, so cost can be grouped any way. Include non-token costs (embeddings, vector DB, GPU-hours, tool APIs) allocated by usage.
  • GPU utilisation (self-hosted): tokens/s per GPU, KV usage, batch size, MFU/bandwidth utilisation (14.7), idle hours; cost per million tokens actually served.
  • Tenant-level usage: usage vs quota and contract, for billing, abuse detection and capacity forecasts (15.9).
