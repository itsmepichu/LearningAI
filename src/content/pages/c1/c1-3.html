A language model assigns probabilities to sequences of text. Modern ones do this one step at a time: given all the text so far, output a probability for every possible next token. Generating text means repeatedly picking a token from that distribution and appending it.

That is the whole core mechanism. Answering a question, writing code and summarising a document are all the same operation: continue the text in a way that is likely given everything before it. Instruction-tuned models have been trained so that the likely continuation of "a user question" is "a helpful answer", but they are still predicting continuations.

A model is called a large language model (LLM) when it combines three things: a transformer architecture; a large number of learned parameters (there is no agreed cut-off; today the term usually means billions, and frontier models are far larger, but parameter count alone does not measure quality: data, training objectives, adaptation and the task matter as much); and pretraining on a very large, broad text corpus (trillions of tokens). The "large" matters because many abilities, such as following instructions in a new format or translating between rare language pairs, only become reliable above a certain scale.

Example: a "question" is just a prefix

Input: Q: What is the capital of Australia?\nA:. The model computes that "␣Canberra" is the most likely next token, then that "." is likely after it, then an end-of-answer token. Nothing in the model is a database row labelled "capital of Australia"; the association is spread across billions of weights.
