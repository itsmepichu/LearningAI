Token: the unit of text a model reads and writes. Usually a word or a piece of a word ("unbeliev" + "ably"). In English prose, 1 token is roughly 4 characters or 0.75 words on average; other languages, code, numbers and identifiers differ widely, so always count with the model's own tokenizer rather than converting from words. Prices, speed and limits are all counted in tokens.
Vocabulary: the fixed list of tokens a model knows, typically 32,000–260,000 entries. Each has an integer ID.
Parameter (weight): one learned number inside the model. An "8B model" has about 8 billion of them. Parameters store everything the model learned.
Embedding: a list of numbers (a vector) that represents a token or a piece of text. Similar meanings get nearby vectors. An embedding is not a compressed copy of the text: you cannot reliably decode the original document from it.
Context window: the maximum number of tokens (input plus output) the model can consider at once, for example 128,000. Anything outside it is invisible to the model.
Training: adjusting parameters so predictions improve. Expensive, done rarely. Inference: using fixed parameters to produce outputs. Cheap per call, done millions of times. Prompting and chatting change only the input, never the weights: a conversation does not retrain the model, and "memory" in chat products is application storage (7.5).
Example: estimating cost before writing code

A summariser receives 3,000-word documents (≈ 4,000 tokens) and writes 200-word summaries (≈ 270 tokens). At an illustrative price of $1 per million input tokens and $4 per million output tokens, one summary costs 4,000 × 1/10⁶ + 270 × 4/10⁶ ≈ $0.005. 100,000 documents a month ≈ $500. Output tokens are usually priced higher and generated much more slowly than input tokens are read, which is why output length dominates latency.

from transformers import AutoTokenizer
tok = AutoTokenizer.from_pretrained("gpt2")          # small download, no model weights
for s in ["Refund my order", "Unbelievably", "Rückerstattung", "退款", "    def f(x):"]:
    ids = tok.encode(s)
    print(f"{s!r:22} {len(ids):2} tokens  {tok.convert_ids_to_tokens(ids)}")

Notice that non-English text and code whitespace take more tokens per character. Try a different tokenizer (for example "Qwen/Qwen2.5-0.5B") and compare counts for the same strings.
