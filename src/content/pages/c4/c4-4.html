Intuition

An embedding gives every piece of text an address in a "meaning space", so that texts about the same thing live in the same neighbourhood. "My bill is wrong" and "invoice error" end up next door, even though they share no words; "giraffe" lives far away.

Nobody draws this map by hand. A network learns it as a side effect of doing some other task well, like predicting missing words or matching questions to their answers. You are known by the company you keep, and so are words.

Mechanism

A representation is the internal vector a network builds for an input. Representation learning means the network learns useful representations as a by-product of its training task. If a model must predict the next word, it is forced to encode meaning, syntax and facts in its vectors.

An embedding is a representation designed to be used directly. Word embeddings (word2vec, 2013) showed that vector arithmetic can capture relations: vec("Paris") − vec("France") + vec("Italy") ≈ vec("Rome"). Today's text embedding models map whole sentences or passages to one vector, trained with contrastive learning: pull matching pairs (question, answering passage) together and push non-matching pairs apart.

Two kinds of embedding are easy to confuse. Token embeddings are the input lookup table inside an LLM (one vector per vocabulary entry). Sentence/document embeddings come from a separate embedding model and are what you store in a vector database for RAG (chapter 9).

The numbers

Storage. One million passages, each embedded as 384 numbers of 4 bytes, take 1,000,000 × 384 × 4 = about 1.5 GB. At 1,024 numbers each, it is about 4.1 GB, which is why embedding size matters for a vector database (9.4).

Free negatives. In contrastive training with a batch of 256 question–passage pairs, each question has 1 right passage and 255 wrong ones already in the batch, so every step teaches 256 small "pick the right one out of 256" lessons at no extra cost.

Reading a similarity. If "invoice" and "bill" score 0.82 and "invoice" and "giraffe" score 0.05 (illustrative), a search for "invoice" will rank bill-related passages first. The exact values depend on the model, so compare scores within one model, never across models.

Code

The program learns word vectors from your example project’s English messages: it counts which words appear near each other, squashes the counts into 16 numbers per word, and lists each word’s nearest neighbours. Change DIM to 4 or 32, or the window of 3 words, and run it again.

Laptop lab: embed and cluster Laptop · CPU
from sentence_transformers import SentenceTransformer
from sklearn.cluster import KMeans
texts = ["invoice overdue", "my bill is wrong", "refund please", "can't log in", "reset password",
         "2FA code not arriving", "package lost", "where is my parcel", "shipping delayed"]
m = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")   # ~90 MB, fast on CPU
E = m.encode(texts, normalize_embeddings=True)
print(E.shape)                                     # (9, 384)
for t, c in zip(texts, KMeans(3, n_init=10, random_state=0).fit_predict(E)): print(c, t)
