Intuition

A neuron is a tiny voting machine. It looks at its inputs, gives each one a weight for how much it matters, adds them up, and then decides how strongly to "fire". A network is many of these in layers, each layer building on what the one below noticed.

Learning means fixing the weights after every mistake. Backpropagation is the blame game run backwards: start at the wrong answer and work back through the layers, telling each weight how much it contributed to the error and which way to move.

Mechanism

Neuron: computes a weighted sum of inputs plus a bias, z = w·x + b, then applies an activation function a = f(z).
Activation: a non-linear function. Without it, stacking layers would collapse into one linear function. Common: ReLU max(0,z); GELU and SiLU (smooth ReLU variants used in transformers); sigmoid and tanh (older, saturate).
Layer: many neurons in parallel, computed as one matrix multiply. A network stacks layers: input → hidden layers → output.
Loss function: mean squared error for regression; cross-entropy for classification and language modelling.
Backpropagation: computes the gradient of the loss with respect to every weight by applying the chain rule backward through the layers, reusing intermediate results.

Logits in, softmax inside. Classification losses such as PyTorch's CrossEntropyLoss expect raw logits and apply (log-)softmax internally in a numerically stable way. Applying softmax yourself first is a common bug: training still runs, but gradients shrink and the model learns slowly.

Example: why non-linearity matters

Two linear layers W₂(W₁x) equal one layer (W₂W₁)x. No matter how deep, a purely linear network can only draw straight decision boundaries. Insert ReLU between them and the network can bend boundaries, which is how it separates, say, a spiral of fraudulent transactions from normal ones.

The numbers

One neuron, by hand. Inputs 1.0 and 0.5, weights 0.8 and −0.5, bias 0.1:

  • Weighted sum: 1.0 × 0.8 + 0.5 × (−0.5) + 0.1 = 0.8 − 0.25 + 0.1 = 0.65.
  • ReLU keeps positive numbers and turns negatives into 0, so the output is 0.65.
  • If the sum had been −0.3, the output would be 0, and so would the gradient: that neuron learns nothing from this example.

Counting weights. A layer from 784 inputs to 128 neurons has 784 × 128 = 100,352 weights plus 128 biases: 100,480 parameters in one small layer.

What a training step costs. The backward pass does about twice the work of the forward pass, so one training step costs about three times as much as just running the model.
