PyTorch gives you tensors that can live on CPU or GPU and autograd: every operation on a tensor with requires_grad=True is recorded in a computation graph, and loss.backward() runs backpropagation through it, filling each parameter's .grad. You write the forward computation; PyTorch derives the backward pass.

Laptop lab: a complete training loop Laptop · CPU · ~1 minute
import torch, torch.nn as nn
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
torch.manual_seed(0)
X, y = load_digits(return_X_y=True)                          # 8x8 images of digits, 1,797 samples
Xtr, Xva, ytr, yva = train_test_split(X / 16.0, y, test_size=0.2, random_state=0)
Xtr, Xva = map(lambda a: torch.tensor(a, dtype=torch.float32), (Xtr, Xva))
ytr, yva = torch.tensor(ytr), torch.tensor(yva)
model = nn.Sequential(nn.Linear(64, 128), nn.GELU(), nn.Dropout(0.1), nn.Linear(128, 10))
opt = torch.optim.AdamW(model.parameters(), lr=3e-3, weight_decay=0.01)
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=40)
loss_fn = nn.CrossEntropyLoss()
for epoch in range(40):
    model.train()
    for i in torch.randperm(len(Xtr)).split(64):                 # mini-batches of 64
        loss = loss_fn(model(Xtr[i]), ytr[i])
        opt.zero_grad(); loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0); opt.step()
    sched.step()
    model.eval()
    with torch.no_grad():
        acc = (model(Xva).argmax(1) == yva).float().mean()
    if epoch % 10 == 9: print(f"epoch {epoch+1} loss {loss.item():.3f} val_acc {acc:.3f}")
torch.save({"model": model.state_dict(), "opt": opt.state_dict(), "epoch": epoch}, "ckpt.pt")
Debugging checklist
  • Overfit one batch first. If the model cannot drive loss near zero on 8 examples, there is a bug (wrong labels, wrong loss, frozen weights).
  • Check the initial loss against ln(number of classes) (2.4).
  • Shapes: print tensor shapes at each step; silent broadcasting causes wrong but runnable code.
  • Train/eval mode: dropout and normalisation behave differently; forgetting model.eval() gives noisy validation numbers.
  • NaN: enable torch.autograd.set_detect_anomaly(True) briefly to find the operation; lower LR; clip gradients.
  • no_grad is not eval mode: torch.no_grad() stops gradient recording but does not disable dropout or switch normalisation to inference behaviour; call model.eval() as well, and model.train() before resuming training.
  • Watch gradient norms per layer; zeros mean a disconnected graph or dead ReLUs.
