Intuition

A deep network is like a long chain of people passing a message by whisper. If everyone speaks a little too quietly, the message fades to nothing by the end; a little too loudly, and it becomes a shout. Gradients passing back through dozens of layers have the same problem.

The fixes are simple habits: start the weights at the right size, re-level the volume at every layer (normalisation), give the message a direct line around each person (residual connections), and cap any sudden shout (gradient clipping). Dropout is a different trick: randomly silencing some people during practice, so the team does not depend on any one of them.

Mechanism

  • Initialisation: weights start as small random numbers with a variance scaled to layer width (Xavier/Glorot, He/Kaiming). Too large and activations explode through the layers; too small and they shrink to zero. All-zero initialisation makes every neuron identical, so they never learn different things.
  • Vanishing / exploding gradients: backprop multiplies many factors. If they are mostly below 1, gradients vanish in early layers (they stop learning); above 1, they explode. Deep networks stay trainable thanks to residual connections (5.3), normalisation and careful initialisation.
  • Normalisation: rescale activations to a stable range. BatchNorm normalises each feature across the batch (common in CNNs). LayerNorm normalises across features within one example (used in transformers because it does not depend on batch size). RMSNorm is a cheaper LayerNorm variant used by many current LLMs.
  • Dropout: during training, randomly zero a fraction of activations (e.g. 10%) so the network cannot rely on any single path. It is turned off at inference.
  • Gradient clipping: if the gradient norm exceeds a limit (often 1.0), scale it down. A cheap guard against loss spikes.
Example: reading a loss spike

Training loss falls smoothly to 2.1, then jumps to 7.8 at step 14,200 and goes NaN. Likely causes: learning rate too high for this phase, a corrupted batch (e.g. extremely long or garbage sequence), or FP16 overflow. Remedies: gradient clipping, lower peak LR, BF16 instead of FP16, skip or inspect the offending batch, resume from the last checkpoint.

The numbers

How fast it fades or explodes. If each of 30 layers shrinks the gradient to 0.7 of its size, the first layer receives 0.7 multiplied by itself 30 times: about 0.00002 of the original. If each layer grows it to 1.3, it arrives about 2,600 times bigger. Small differences per layer become huge over depth.

The right starting size. He initialisation for ReLU layers 256 wide draws weights with a spread of about 0.09 (the square root of 2 ÷ 256). That keeps the signal roughly the same size from layer to layer.

Dropout keeps the average. Dropping 10% of values and multiplying the other 90% by 1 ÷ 0.9 ≈ 1.11 leaves the average unchanged, so nothing needs adjusting when dropout is turned off for real use.

Clipping. If the gradient’s overall size is 5.0 and the limit is 1.0, every number in it is multiplied by 1.0 ÷ 5.0 = 0.2. The direction stays the same; only the step gets smaller.

Code

The program sends a batch of data through 50 random ReLU layers with weights that are too small, too big and correctly scaled, then through too-big layers with residual connections and normalisation, and checks that dropout keeps the average. Change DEPTH or the scales and run it again.
