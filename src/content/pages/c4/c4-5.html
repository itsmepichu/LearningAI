Intuition

Before transformers, two designs did most of the work. A CNN looks at an image through a small window that it slides everywhere, like scanning a page with a magnifying glass: the same "edge detector" works in every corner. An RNN reads a sentence one word at a time and keeps a running summary in its head, like listening to a long story and trying to remember the beginning.

The magnifying glass is efficient but only sees a little at once. The running summary forgets the start of long stories, and it cannot be hurried, because each word has to wait for the one before. Attention fixed both problems, but these designs still turn up in vision, OCR and small time-series models.

Mechanism

  • Convolutional neural networks (CNNs) slide small learned filters (kernels) across an image, detecting local patterns (edges → textures → parts → objects). Weight sharing makes them efficient. Still used for vision and OCR components in document pipelines.
  • Recurrent neural networks (RNNs) process a sequence one element at a time, updating a hidden state ht = f(W·xt + U·ht−1). The same weights are applied at each step. Information from early tokens must survive many multiplications, so it fades.
  • LSTMs add a cell state and gates (forget, input, output) that learn what to keep, write and expose, which preserves information over longer spans. GRUs are a simpler variant.
  • Sequence-to-sequence (seq2seq): an encoder RNN reads the input into a vector; a decoder RNN generates the output from it. The single fixed vector is a bottleneck for long inputs, which is exactly what attention was invented to fix (1.2, 5.2).
Example: where these still appear

A document-ingestion pipeline (10.3) may use a CNN-based layout detector and a CNN/transformer OCR model before any LLM sees the text. Time-series anomaly detectors on GPU telemetry sometimes use LSTMs because they are small and fast.

The numbers

Why sharing weights is cheap. A 3 × 3 filter has 9 weights, and the same 9 are reused at every one of the roughly 50,000 positions in a 224 × 224 image. A fully connected layer linking all 50,176 pixels to 50,176 outputs would need 50,176 × 50,176 ≈ 2.5 billion weights.

How fast an RNN forgets. If each step keeps half of the old state, the first word’s share after 20 steps is 0.5 multiplied by itself 20 times: about one millionth. LSTM gates learn to keep more, but very long inputs still fade.

Why RNNs train slowly. A 1,000-word input takes 1,000 steps one after another, because each step needs the result of the one before. A transformer processes all 1,000 positions of a training example at once.

Code

The program counts your example project’s records per day, slides two hand-made filters along the series (a 7-day average and a change detector), and then shows how fast a plain RNN’s memory of its first input fades. Change the EDGE filter or KEEP and run it again.
