Vendor benchmarks use clean public datasets, single tenants, no filters and no writes. Your benchmark must reproduce your conditions:

  • Realistic queries: sampled from logs (or written by users), with relevance labels (9.7), in the real mix of lengths, languages and filters.
  • Realistic filters: permission filters that are selective (a user sees 2% of the corpus) behave very differently from no filter in many ANN engines.
  • Concurrent updates: run the query load while upserts and deletes stream in at production rates; HNSW graphs and segment merges can hurt latency and recall during heavy writes.
  • Measure together: recall vs exact search, end-to-end Recall@k vs labels, latency percentiles (p50/p95/p99) at target QPS, resource usage, and cost per million queries.
  • Scale steps: run at 10%, 30%, 100% of the target corpus to see the trend; do not extrapolate from a 1% sample alone.
Laptop lab: ANN benchmark at 1M vectors Laptop · CPU · 16 GB RAM
import numpy as np, faiss, time
d, n, nq = 384, 1_000_000, 1_000
rng = np.random.default_rng(0)
xb = rng.standard_normal((n, d), dtype=np.float32); faiss.normalize_L2(xb)       # ~1.5 GB
xq = rng.standard_normal((nq, d), dtype=np.float32); faiss.normalize_L2(xq)
flat = faiss.IndexFlatIP(d); flat.add(xb); _, gt = flat.search(xq, 10)        # exact ground truth
hnsw = faiss.IndexHNSWFlat(d, 16, faiss.METRIC_INNER_PRODUCT); hnsw.hnsw.efConstruction = 80
t = time.time(); hnsw.add(xb); print(f"build {time.time()-t:.0f}s")               # several minutes on CPU
for ef in (16, 32, 64, 128, 256):
    hnsw.hnsw.efSearch = ef; t = time.time(); _, I = hnsw.search(xq, 10); dt = (time.time()-t)/nq*1000
    rec = np.mean([len(set(I[i]) & set(gt[i]))/10 for i in range(nq)])
    print(f"efSearch={ef:4}  recall@10={rec:.3f}  {dt:.2f} ms/query")

Limitation: random vectors are harder for ANN than real embeddings (no cluster structure), so recall here is pessimistic, and the test has no filters, writes or network. It does teach the efSearch curve and memory behaviour. Real-quality benchmarks need your embedded corpus.
