Vectors from different embedding models live in different spaces; you cannot compare a query embedded with model B against documents embedded with model A. Changing the embedding model (or its dimensions, or even the chunker) therefore requires re-embedding the whole corpus, which at scale takes days and real money. Example: the version bound together

An index is not just vectors: it is (embedding model + version, dimensions, normalisation, chunker config, parser version, ANN parameters). Store these as an index manifest. A query service that loads the manifest and refuses to query an index whose embedding model differs from its own prevents the silent failure where cosine scores look fine but results are random.

In practice · HarborHarbor's index manifest binds embedder v2 to index v2; rollback switches both the alias and the query encoder together.
