Who this course is for

For beginner programmers and students who know basic Python; it ends at building professional AI applications. You do not need to know any machine learning, mathematics beyond school arithmetic, or any AI tool. Every new term is explained where it first appears, and you can look it up again in the Glossary, linked in the sidebar.

The course is one sequence. Every chapter, section and topic is required, and each chapter builds on the ones before it, so work through them in order.

What you need

  • Python basics: variables, lists, dictionaries, loops, functions, and reading a file.
  • A browser: Part I runs in your browser. The figures and the small Python snippets run on this page, with nothing to install.
  • A terminal, from Part II on: you will run short Python programs on your own laptop. Each lab says what to install, and only when you first need it. Nothing is installed up front.
  • A laptop, no GPU: everything runs on an ordinary laptop. The few topics that need a GPU give a step-by-step guide for a free Google Colab session instead.

Check your Python basics

Try each question in your head or in a Python prompt, then open the answer. If you miss more than two, work through the official Python tutorial first: docs.python.org/3/tutorial. Nothing here is saved or scored.

  1. names = ["ana", "bo", "cy"]. What does names[1] give?

    Answer

    "bo". A list starts counting at 0, so index 1 is the second item.

  2. What does len("hello world") return?

    Answer

    11. It counts every character, including the space.

  3. ages = {"ana": 31, "bo": 27}. How do you read Bo's age, and how do you add Cy, who is 45?

    Answer

    ages["bo"] gives 27. ages["cy"] = 45 adds the new key.

  4. What does this print? total = 0, then for n in [2, 3, 5]: total = total + n, then print(total)

    Answer

    10. The loop adds 2, then 3, then 5 to the running total.

  5. Write a function double(x) that returns twice its input.

    Answer

    def double(x): on one line, then return x * 2 indented below it. double(4) gives 8.

  6. What does [w.upper() for w in ["a", "b"]] give?

    Answer

    ["A", "B"]. It is a list comprehension: a short way to build a new list by changing each item.

  7. What does "to be or not to be".split() give?

    Answer

    A list of the words: ["to", "be", "or", "not", "to", "be"]. Without an argument, split cuts at spaces.

  8. How do you read a text file called notes.txt into one string?

    Answer

    with open("notes.txt") as f:, then text = f.read() indented below it. The with block closes the file for you.

  9. What does "cat" in "concatenate" give, and what does 3 in [1, 2, 4] give?

    Answer

    True for the first, because "cat" appears inside the word. False for the second, because 3 is not in the list.

  10. What is the difference between 5 / 2, 5 // 2 and 5 % 2?

    Answer

    2.5 is ordinary division, 2 is whole-number division that drops the remainder, and 1 is the remainder.

How a topic works

Each topic has the same five parts, in the same order:

  1. Intuition: the idea in plain words, with an analogy and no symbols.
  2. Mechanism: how it works, step by step, with a figure you can step through or change.
  3. The numbers: small worked examples with real arithmetic, such as 240 ÷ 100 = 2.4.
  4. Code: a short program you can run, with a line on what to change to see something different.
  5. Primary sources: the papers and official documentation behind the topic, each with a line on why it is there.

Between Code and Primary sources, an In practice card shows the idea inside an example system: what a team does with it, a mistake to avoid, and something to try.

Look at the tags on a topic. A tag tells you what kind of result a figure gives you: Runs in browser is real computation, Simulation is an animated model with made-up numbers, Laptop · CPU runs on your laptop, and Colab · GPU needs a free Google Colab session. A simulation shows the shape of a trade-off; it does not measure anything.

Run a snippet in your browser

Many topics have a Code section with a box that runs Python on the page. Press Run to execute it and see the output below. You can edit the code and run it again. The box says what the result shows and what it does not show. It uses only the Python standard library and NumPy, so there is nothing to install. Topic 1.4 has one you can try now.

Open a dataset

The course uses four example systems, all fictional, each with small made-up data files. The In practice card of a topic names the file to use. Download it from the card and open it in any spreadsheet or in a text editor. These files are CSV or JSON: plain text, one record per line or per object. Counting rows, finding the most common value and spotting what looks wrong are the first skills you will use.
