Confusion matrix: counts of true positives (TP), false positives (FP), true negatives (TN), false negatives (FN).
Precision = TP/(TP+FP): of everything flagged, how much was right. Recall = TP/(TP+FN): of everything that should be flagged, how much we caught.
F1 = 2·P·R/(P+R): harmonic mean, high only if both are high.
ROC curve: true positive rate vs false positive rate across all thresholds; AUC summarises it (0.5 = random, 1 = perfect). PR curve: precision vs recall across thresholds; more informative when positives are rare.
Calibration: a model is calibrated if, among cases it scores 0.8, about 80% are positive. Shown with a reliability diagram; summarised by expected calibration error (ECE).
Example: choosing the threshold from costs

A missed fraud costs $400; a false alarm costs $5 of analyst time. Expected cost = 400·FN + 5·FP. Sweep thresholds on validation data and pick the minimum; with these costs it will sit at a low threshold (high recall). If false alarms instead block customers' cards (cost $60 in churn), the optimum moves up. Metrics serve a business cost function, not the other way round.

In practice · HarborHarbor's escalation classifier must keep precision ≥ 80% (human reviewers have limited capacity) while maximising recall; F1 is reported but not used to pick the threshold.
