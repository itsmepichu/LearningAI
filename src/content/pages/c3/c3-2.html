• Regression predicts a number (delivery time, price). Linear regression fits y = w·x + b by minimising squared error.
  • Classification predicts a category. Logistic regression outputs a probability via the sigmoid σ(z) = 1/(1+e−z); a threshold turns it into a decision.
  • Clustering groups similar points. k-means alternates two steps: assign each point to its nearest centre, then move each centre to the mean of its points.
  • Decision trees split data with yes/no questions on features ("amount > 500?"). Easy to read, but a single deep tree overfits.
  • Ensembles combine many models. Random forests average many trees trained on random subsets. Gradient boosting (XGBoost, LightGBM, CatBoost) adds trees one at a time, each correcting the previous errors. For tabular data, gradient boosting is usually the strongest practical choice.
  • Baselines are the simplest reasonable models: always predict the most common class, predict the mean, a keyword rule. If your sophisticated model barely beats the baseline, it is not adding value. Always report the baseline next to your result, including for LLM systems.
Example: baselines keep you honest

A ticket classifier reports 91% accuracy. But 88% of tickets are "general", so always predicting "general" scores 88%. The real gain is 3 points, and recall on the rare "security incident" class might be terrible. Report per-class metrics (3.5) and the baseline.

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
X, y = load_breast_cancer(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)
for name, m in [("baseline", DummyClassifier(strategy="most_frequent")),
                ("logistic", make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))),
                ("boosting", HistGradientBoostingClassifier(random_state=0))]:
    print(f"{name:9} accuracy = {m.fit(Xtr, ytr).score(Xte, yte):.3f}")
